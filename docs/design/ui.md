
## tool bock设计

### 总思路

``` tool block 闭合状态

 ┌───────────────────────────────────────┐
 │ tool name                             │
 │ tool args                             │
 └───────────────────────────────────────┘

```


```  tool block 点击后展开状态

 ┌───────────────────────────────────────┐
 │ tool name                             │
 │ tool args                             │
 │                                       │
 │ tool results                          │
 │                                       │
 │                                       │
 │                                       │
 │                                       │
 └───────────────────────────────────────┘

```
