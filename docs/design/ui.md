``` 

 ┌───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
 │  tab 栏                                                                                                                           │
 ├───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
 │                                                                                                                                   │
 │                                                                                                                                   │
 │                                                                                                                                   │
 │                                                                                                                                   │
 │     对话栏                                                                                                                        │
 │                                                                                                                                   │
 │                                                                                                                                   │
 │                                                                                                                                   │
 │                                                                                                                                   │
 │                                                                                                                                   │
 │                                                                                                                                   │
 ├───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
 │                                                                                                                                   │
 │                                                                                                                                   │
 │    输入栏                                                                                                                         │
 │                                                                                                                                   │
 │                                                                                                                                   │
 ├───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
 │ {{session_id}} | {{model_name}}({{provider}}) | {{status}}                                            Ctrl-d: quit | /help = help │
 │ {{workdir_path}}               Tokens: {{input}} input / {{output}} output | Cache: {{cache_create}} create / {{cache_read}} read │
 │                                                                                                                                   │
 └───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
     ▲
     │
   状态栏

   workdir_path根据长度做一下动态压缩，优先是全长度，如果算上后面的token数据再加上workdir_path与"Tokens"中间间隔的四个空格，长度超过一行的话，就压缩workdir_path中间部分的内容，用“...”替代，如果这样还是超长的话，就压缩workdir_path的头部内容，变成类似".../xxx"的形式

   Tokens和Cache的内容也可以压缩，比如input超过一万，就可以用10.xxk来表示，xx表示两位小数，同理，超过千万就是10.xxm，超过百亿就是10.xxb


```

## 子Agent 在主agent tab中的ui

`show in new tab` 是一个按钮，点击可以打开子agent tab，如果agent tab已经打开，则切换到该tab

``` 闭合

 ┌─────────────────────────────────────────────────────┐ 
 │ agent_name: agent_session_id   [show in new tab]    │ 
 │ agent prompt第一行                                  │ 
 └─────────────────────────────────────────────────────┘ 

```                             

```  tool block 点击后展开状态

 ┌─────────────────────────────────────────────────────┐
 │ agent_name: agent_session_id   [show in new tab]    │ 
 │ agent 完整 prompt                                   │
 │ agent result                                        │
 │                                                     │
 └─────────────────────────────────────────────────────┘

```
