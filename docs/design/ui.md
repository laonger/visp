
## tool bock设计

### 总思路

``` tool block 闭合状态

 ┌───────────────────────────────────────┐
 │ tool name                             │
 │ tool args                             │
 └───────────────────────────────────────┘

```


```  tool block 点击后展开状态

 ┌───────────────────────────────────────┐
 │ tool name                             │
 │ tool args                             │
 │                                       │
 │ tool results                          │
 │                                       │
 │                                       │
 │                                       │
 │                                       │
 └───────────────────────────────────────┘

```

## 子Agent 在主agent tab中的ui

`show in new tab` 是一个按钮，点击可以打开子agent tab，如果agent tab已经打开，则切换到该tab

``` 闭合

 ┌─────────────────────────────────────────────────────┐ 
 │ agent_name: agent_session_id   [show in new tab]    │ 
 │ agent prompt第一行                                  │ 
 └─────────────────────────────────────────────────────┘ 

```                             

```  tool block 点击后展开状态

 ┌─────────────────────────────────────────────────────┐
 │ agent_name: agent_session_id   [show in new tab]    │ 
 │ agent 完整 prompt                                   │
 │ agent result                                        │
 │                                                     │
 └─────────────────────────────────────────────────────┘

```
