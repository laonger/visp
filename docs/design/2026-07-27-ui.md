### 状态栏

``` 

 ├───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
 │ {{session_id}} | {{model_name}}({{provider}}) | {{status}}                                            Ctrl-d: quit | /help = help │
 │ {{workdir_path}}                                    Tokens: {{input}}i / {{output}}o | Cache: {{cache_create}}c / {{cache_read}}r │
 │                                                                                                                                   │
 └───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
     ▲
     │
   状态栏

   workdir_path根据长度做一下动态压缩，优先是全长度，如果算上后面的token数据再加上workdir_path与"Tokens"中间间隔的四个空格，长度超过一行的话，就压缩workdir_path中间部分的内容，用“...”替代，如果这样还是超长的话，就压缩workdir_path的头部内容，变成类似".../xxx"的形式

   Tokens和Cache的内容也可以压缩，比如input超过100，就可以用0.xk来表示，x表示一位小数，同理，超过十万就是0.xm，超过亿就是0.xb

   单击session_id可以将其复制到系统粘贴板，我们有粘贴板功能，请直接复用


```

### 输入栏

#### 正在推理时

推理时输入框与输入状态保持同一几何高度（不塌缩）。输入框内以占位文本（placeholder）显示状态行：

```

  Generating ...  {{tokens_per_second}} tokens/s output

```

（显示于输入框内部，推理期间输入被禁用、输入框为空时可见；流刚开始（< 0.5s）时速率为 --）

tokens_per_second 是实时速度（流式估算，随输出持续刷新）


### 对话栏

#### assistant block

```

 ├───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
 │ {{message}}                                                                                                                       │
 │                                                                                                                                   │
 │ [{{time}} | Tokens {{token_input}} in / {{token_output}} out on {{token_speed}} t/s | Tools: {{tool_call_amount}}]          │
 │                                                                                                                                   │
 │                                                                                                                                   │
 ├───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤

 ```

（assistant 消息无边框渲染，正文占满整行宽度；统计页脚与正文之间空一行）

token_speed 是最终统计速度：结算输出 tokens（即 token_output）/ 本次流总耗时，流结束时冻结；与输入栏的实时速度（tokens_per_second）是两个不同指标。

## 鼠标拖拽选择高亮

对话区支持鼠标拖拽选择文本：选中区域涂浅蓝色（`theme::SELECTION_BG`），松开左键自动复制（OSC 52 / 系统剪贴板），Esc 清除选择。

**block 行为约束：拖拽时只涂蓝 block 内的内容**（`ui.rs: apply_selection_highlight` + `app.rs: BlockRows`）：

- 渲染时 `render_block` / `render_image_block` 记录每个屏幕行的归属（`AppState.block_rows`，每帧全量重建）：
  - **内容行** → 内容列范围 `(x_start, x_end)`，高亮只涂内容列（跳过左右 `margin_horizontal` 边距列与右侧阴影列）
  - **留白行**（`top_margin` 空气行 / `margin_vertical` 内边距行 / 底部阴影行）→ 整行跳过高亮
- 不在表中的行（block 之间的空气行、输入区、状态栏等）保持原有的全宽高亮
- 复制内容提取（`extract_selected_text` / 溯源层）不受影响，仍按选区矩形提取原文
